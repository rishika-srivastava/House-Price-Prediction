# 🏡 House Price Prediction System

## About the Project
This project uses Machine Learning to predict historical median house values for California districts using the California Housing Prices dataset.

## Models Used
- Linear Regression
- Random Forest Regressor

## Features
- Data preprocessing and missing-value handling
- Numerical feature scaling and categorical encoding
- Interactive house-value predictions
- Model evaluation using MAE, RMSE, and R²
- Gradio web interface

## Technologies Used
- Python
- Pandas and NumPy
- Scikit-learn
- Gradio
- Google Colab

## Model Performance
The Random Forest model achieved an R² score of approximately **0.817** on the test set.

## How to Run
1. Open `house (1).ipynb` in Google Colab.
2. Upload the required `housing.csv` dataset.
3. Run the notebook cells in order.
4. Open the Gradio link generated at the end to try the app.

## Dataset Note
The predictions represent historical California district-level median house values, not current valuations of individual homes.
